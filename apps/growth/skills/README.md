# Growth skills

Three Claude Code skills that drive the [Growth app](..). Each folder holds a `SKILL.md` (the instructions Claude reads) and a `README.md` (for you).

| Skill | What it is for | Start with |
|---|---|---|
| [growth](growth) | Your own career growth: onboarding interview, nightly tasks, plans, CV and case studies | `growth start` |
| [growth-coach](growth-coach) | The coaching rules behind Growth: answers the work the app queues | `answer it` |
| [g-mini](g-mini) | Helping someone else with one career move: one interview, one PDF report | `/g-mini new` |

Install all three with `node ../install.mjs`, or one with `node ../install.mjs --only=g-mini`. Details are in the [Growth README](../README.md#install).
