# Journal

The Journal is where wins, feedback, what you learned, where you applied and what you made go. All of it counts as evidence.

## Add an entry

Press `J` anywhere in the app, or open the Journal page. Pick what happened.

| Kind | Use it for |
|---|---|
| Win or feedback | Someone said something about your work, or reached out to you. Write it as close to their words as you can. |
| Learned | Something you understood today, in your own words, as if you were explaining it to a friend. Tie it to a gap and Claude counts it toward closing that gap. |
| Applied to a job | Where you applied, and for which role. It asks for the company and the role. |
| Made | Something you designed, built or shipped, at work or on the side. |

Entries from Tonight's closing line show as "Tonight".

## How entries are labelled

The app labels each entry by what it is.

| Label | Source type |
|---|---|
| Made | `shipped` |
| Feedback | `expert` |
| Done | `self` |
| Result | `market` |
| Applied | `market` (an application) |
| Claude's review | `ai` |
| Learned | A learning note |

The type sets how much trust the entry carries. See [Honesty rules](../concepts/honesty-rules.md). Your own words are saved as you wrote them. Link an entry to a skill, and it counts toward that skill on [You](you.md).

## How it is grouped

The page shows this week first, then recent weeks, each under "Week of ...". Nothing is deleted when a week ends.

## Ask Claude to read it

Say `read my journal` in Claude Code. Claude reads your log back as themes, wins and blockers that repeat. It changes nothing. You can ask for a week (`journal read week`), one gap (`journal read gap <id>`) or the last few days (`journal read 14 days`).

You can also add a line from Claude Code with `journal <what happened>` or `journal add <what happened>`.

{% hint style="info" %}
Round 3 answers from the interview never go into the journal. Journal entries that could be shared stay free of confidential items.
{% endhint %}

Related commands: `journal`, `journal add`, `journal read`, `fraud`, `remember`. See [Commands](../reference/commands.md). Next: [Library](library.md).
